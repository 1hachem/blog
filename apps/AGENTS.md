# Applications

Deployable entry points. Each app owns its runtime, deployment configuration,
dependencies, and scripts.

- `blog` — the Astro site. See `blog/AGENTS.md`.
- `animations` — Remotion Studio (`pnpm dev`) and the renderer (`render.mjs`) for
  `packages/animations`.

Add a package-level `AGENTS.md` when an app needs guidance beyond this file.
